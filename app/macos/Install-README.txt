Installing Lampstand on a Mac

1. Drag Lampstand onto the Applications folder in this window.
2. Open Applications and double-click Lampstand.
   If the Mac says it can't check the app for malicious software, right-click Lampstand,
   choose Open, then choose Open again. You only need to do this the first time.
3. The first time you use a camera, microphone or screen capture, the Mac asks for
   permission. Choose Allow.

Updating from an older copy
If screen sharing says it needs permission even though Lampstand is switched on in
System Settings, open Cameras & screens in Lampstand and press the three buttons in order:
1. Reset permission, 2. Ask for access (choose Allow), 3. Restart Lampstand.
This is needed once; from this version on, updates keep the permission.

FFmpeg (needed for streaming, recording, videos, music and cameras)
Lampstand uses the free FFmpeg program. If it isn't installed yet:
  1. Install Homebrew from https://brew.sh
  2. In Terminal, run:  brew install ffmpeg
Lampstand finds it by itself. Stream setup shows whether it was found.

Works on Macs with Apple chips and with Intel chips, macOS 11 or newer.
